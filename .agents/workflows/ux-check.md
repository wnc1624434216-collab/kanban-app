# 🎨 看板應用 UX 檢核工作流程 (UX Check Workflow)

本文件定義看板應用（Kanban App）的使用者體驗（UX）、互動流暢度與視覺層次的標準檢核流程。每當介面樣式、排版或互動邏輯有所調整時，請依據本流程進行檢視。

---

## 檢核流程概要

```
1. 表單輸入防呆 ──> 2. 視覺層次與標籤 ──> 3. 拖曳與互動回饋 ──> 4. 響應式排版 (RWD) ──> 5. 資料持久化
```

---

## 1. 表單輸入體驗檢核 (Input & Form UX)

* [ ] **防呆驗證**：
  * 任務標題為必填，若輸入全形/半形空白或未輸入，表單應阻止送出並提示使用者。
* [ ] **選填欄位直覺度**：
  * 截止日期欄位標記「可選填」，未填寫時亦可正常新增任務。
* [ ] **操作連貫性**：
  * 表單提交後，輸入框內容應自動清空，並讓游標重新聚焦（Focus）於任務輸入框，方便連續輸入。
* [ ] **鍵盤無障礙操作**：
  * 在輸入框按下 `Enter` 鍵應能直接觸發送出新增任務。

---

## 2. 視覺層次與資訊可讀性 (Visual Hierarchy & Readability)

* [ ] **欄位狀態與數量統計**：
  * 三欄（待處理、進行中、已完成）標題是否具備清晰的圖示與即時數量計數 Badge。
  * 卡片數量為 0 時，欄位應維持一定的最小高度（Min-height），避免版面塌陷。
* [ ] **卡片內容排版**：
  * 長文字或連續無空格字串（如長網址）是否具備自動折行（`word-break: break-word`），不可撐破卡片邊界。
* [ ] **截止日期標籤檢視**：
  * **未填日期**：卡片上保持乾淨，不顯示多餘的空白標籤或佔位符。
  * **正常未逾期**：顯示柔和淺灰色背景（`.due-tag`），日期格式必須為 `YYYY/MM/DD`。
  * **今天或已逾期**：自動切換為醒目紅色警示樣式（`.due-tag.overdue`：紅底、紅字、紅邊框），能第一時間吸引使用者注意力。
* [ ] **危險操作辨識**：
  * 卡片刪除按鈕（`✕`）平時應保持低干擾灰色，滑鼠懸停（Hover）時切換為警告紅色。

---

## 3. 拖曳與操作互動回饋 (Interaction & Drag-and-Drop)

* [ ] **滑鼠指針反饋**：
  * 滑鼠移動到卡片上時，游標應切換為抓取狀態（`cursor: grab`），按住拖曳時切換為 `grabbing`。
* [ ] **拖曳中視覺回饋**：
  * 被拖曳中的卡片是否具備半透明效果（`opacity: 0.5`），讓使用者清楚感知正在移動該物件。
* [ ] **目標放置區域 (Drop Zone)**：
  * 不論目標欄位內已有其他卡片或是完全空白，皆能順利將卡片拖入該欄位。
* [ ] **狀態即時同步**：
  * 卡片放下後，來源欄位與目標欄位的數量計數必須立即且正確地加減更新。

---

## 4. 響應式與跨裝置體驗 (Responsive Design UX)

* [ ] **桌面端寬螢幕 (>= 1024px)**：
  * 三欄並排等寬展示，左右間距舒適，水平居中對齊。
* [ ] **平板與窄螢幕 (< 1024px, >= 768px)**：
  * 欄位自動依空間自適應調整寬度或以 2 欄 / 1 欄排版，不產生非預期的水平滾動條（Horizontal Scroll）。
* [ ] **行動裝置 (< 768px)**：
  * 表單元素自動垂直堆疊，按鈕寬度擴展至全寬以便於拇指觸控點擊。
  * 看板欄位改為垂直單欄排列。
  * 刪除按鈕點擊熱區（Touch Target）不應過小（建議至少 24x24px 以上）。

---

## 5. 資料保存與狀態恢復 (Persistence & Recovery)

* [ ] **跨重新整理測試**：
  * 新增、移動、刪除卡片後，重新整理瀏覽器頁面（F5），所有卡片的位置、內容與日期標籤狀態皆完整還原。
* [ ] **首次訪問體驗**：
  * 若為全新使用者（無 LocalStorage 記錄），應提供恰當的預設示範卡片，引導使用者理解看板功能。

---

## 檢核步驟指引 (How to Run)

1. 在專案根目錄以瀏覽器開啟 `index.html`。
2. 依序新增以下四種情境任務：
   * 情境 A：純文字任務，不填日期。
   * 情境 B：填寫未來日期（例如一週後）。
   * 情境 C：填寫今天日期。
   * 情境 D：填寫過去日期（例如昨天）。
3. 檢查卡片標籤顏色（A 無標籤、B 灰標籤、C 與 D 為紅標籤）。
4. 開啟瀏覽器 DevTools（F12）切換至「行動裝置模擬模式 (Responsive Mode)」，檢查寬度 375px 下的排版。
5. 將卡片來回拖曳至各欄位，確認計數與重新整理後資料依然正確。
